# Проверка backend, 26.10.2026

Backend проверен с настоящим OpenAI-совместимым endpoint и read-only источниками. Полная приёмка всех внешних возможностей не заявляется: Tavily не имеет ключа, некоторые источники нестабильны. Машинный отчёт: [travel_agent_smoke.json](../reports/travel_agent_smoke.json).

## Автоматические проверки

- Обычный `unittest discover`: 30 успешных тестов, 1 PostgreSQL-тест пропущен; внешние сети и LLM не вызываются.
- С `TRAVEL_TEST_DATABASE_URL` на отдельном PostgreSQL 17: все 31 тест проходят.
- `uv pip check` — совместимость подтверждена. Wheel собран с четырьмя Markdown-промптами.
- Исходные 12 исследовательских тестов сохранены.

Проверены обязательные поля/даты, Decimal/basis, неизвестные расходы, устаревшие котировки, география трёх районов, deny-before-network и чужие Tutu IDs, timeout, missing_key, ограничения ReAct, фильтрация injection metadata, отсутствие structured output, диалог и продолжение, выборочная пересборка, изоляция пользователей, revision conflict, явное подтверждение и идемпотентность simulation. Fixtures содержат сокращённые реальные ответы исследовательского стенда; время теста задаётся отдельно и не выдаётся за новую live-проверку.

## Live LLM + граф

Один успешный сквозной прогон:

1. «Из Москвы в Сочи, двое взрослых, 100000 рублей» → вопрос о датах, без поиска.
2. «12–16 ноября 2026» → реальные Tutu avia/hotel searches, Experience с 2GIS и погодным контекстом.
3. Получены три варианта с транспортом, проживанием и пятью днями программы. По шесть каталожных активностей на вариант; точные часы посещения не обещаются.
4. Известные суммы на момент этого прогона: 19058, 19058 и 19408 RUB. Полные суммы — null. После этого улучшено разнообразие альтернатив: выбираются разные отели, если есть проверенные кандидаты.

В отдельном extended-прогоне первый поиск вернул частичный план без отеля; это сохранено в отчёте, а не скрыто. Последующая просьба выбрать Mirror Residence дала полный вариант. При замене отеля Transport не запускался: сохранённый transport result совпал полностью, включая время evidence. При сдвиге на 13–17 ноября Transport, Stay и Experience запускались заново; транспорт и проживание получили новые данные. Полная стоимость осталась неизвестной.

Обнаруженные и исправленные ошибки:

- Лишние detail-запросы и повторные поиски: компактный tool context, reuse одинакового MCP-вызова внутри делегации, уточнённые условия завершения.
- Structured output иногда возвращал `None`: отдельная runtime-валидация, проверенные evidence сохраняются с предупреждением, добавлен regression test.
- Пустая модельная selection больше не уничтожает наблюдённые кандидаты; возвращается `empty_selection`. Это проверено офлайн; отдельный новый live-прогон только этой последней ветки не выполнялся.
- Timepad coordinates оказались массивом `[lat, lon]`: адаптер исправлен, fixture-тест и повторный live вызов вернули три события.

Experience может исчерпать deadline и вернуть partial. Отсутствие прогноза на ноябрьские даты отмечено `weather_outside_forecast_horizon`, а не заменено сезонной догадкой.

## API и память

На отдельном PostgreSQL проверены закрытие/открытие saver и store, продолжение диалога и восстановление профиля. Дополнительно запущены два независимых lifespan реального FastAPI-приложения: в первый загружен неизменённый результат текущего live-графа, выполнены выбор и явно подтверждённая simulation; повтор запроса вернул тот же booking. Второй lifespan восстановил поездку, выбранный вариант и booking из PostgreSQL. Это проверка API на live evidence, а не дополнительный автономный LLM-диалог через HTTP.

CLI работает через те же HTTP endpoints; argument parsing проверен. Интерактивный ручной live-сеанс CLI не записывался; автоматическая приёмка диалога и booking выполнена через граф и FastAPI TestClient.

## Расход и границы

Пользователь разрешил до $1, только read-only. Первый неудачный запуск остановлен консервативным guard; финальная стоимость не сохранилась, поэтому для него зарезервирован весь предел $0.65. Остальные три запуска сообщили через endpoint `usage.cost`: $0.0062579208, $0.005599391 и $0.0128584190. Совокупная консервативная оценка LLM: **не более $0.6747157308**. Это не точный счёт первого запуска. Провайдерские API не сообщают долларовый usage; использовались существующие ключи/квоты, платные операции и покупки не включались.

Никаких реальных бронирований, пассажирских операций и платежей не выполнено. `.env`, `MODEL`, `TOKEN` и `BASE_URL` не изменены. Непроверенные часы работы, трансферы, наличие и полные расходы остаются ограничениями, а не вымышленными подтверждениями.
