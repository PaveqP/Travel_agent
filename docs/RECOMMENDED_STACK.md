# Рекомендуемый стек MVP

По результатам 25.10.2026 MVP технически возможен с Tutu, 2GIS, Яндекс Расписания, Geoapify и Open-Meteo. ETG недоступен по условиям задачи. Полная цена поездки пока не подтверждена: ресторанные счета, местные переезды, подъёмники и дополнительные сборы неизвестны. Успешный поиск не гарантирует сохранение тарифа до покупки.

| Назначение | Основной источник | Резерв / ограничение |
|---|---|---|
| Отели и live поисковые тарифы | Tutu MCP, P0 | LiteAPI даёт каталог Сочи, но sandbox не дал тарифов; полноценного независимого резерва проживания нет |
| Перелёты | Tutu MCP, P0 | Travelpayouts Data API, P1: только кэш/ценовой ориентир, не замена наличия |
| Электрички и поезда | Яндекс Расписания REST, P0; Tutu MCP | Сначала разрешить station ID, не путать тариф с доступным местом |
| POI, рестораны, логистика | 2GIS MCP, P0 | Geoapify REST/MCP P0; ORS P1 для маршрутов; Nominatim/OSRM P2 для ограниченного прототипа |
| События и экскурсии | Timepad REST P1 | OpenTripMap P2 для статических мест; партнёрские экскурсии пока недоступны |
| Погода | Open-Meteo Forecast P0 | Marine/Air/Elevation P1/P2; коммерческое использование free endpoint требует проверки тарифа |
| Валюта | ЦБ РФ P1 | Дата курса обязательна; расчёт Decimal в Python |
| Покупка | Ссылка поставщика | Никаких автоматических денежных операций |

Tutu реально вернул 10 round-trip предложений и 40 строк проживания (32 уникальных отеля). Минимальный round-trip на двоих — 14 018 RUB, условия багажа различаются по тарифу. Для отелей цена уже за четыре ночи и двоих: повторное умножение на ночи/гостей — ошибка. Перед выдачей проверять соответствие района координатам: «Красная Поляна» разрешилась в курорт, выдача Сочи включает горный кластер. Два вызова hotel details завершились ConnectTimeout, поэтому полные правила отмены/налоги/адрес не подтверждены детальным endpoint. Инициализация Tutu также сначала не проходила; нужна обработка временных сетевых ошибок.

LiteAPI production для России не проверялся. Нулевой sandbox availability не означает доказанное глобальное отсутствие покрытия, но включать его в MVP как рабочий резерв цен нельзя. Boston был отдельным sandbox-контролем: одна выдача тарифов успешна, повторная для prebook пустая. Prebook/book не выполнены из-за отсутствия свежего offerId; реальные бронирования не совершались.

KudaGo и Wikidata вернули 403, Overpass — таймауты трёх документированных публичных экземпляров. Это ограничения доступа из текущего окружения, а не отсутствие данных Сочи. OpenWeather MCP не подключился; WeatherAPI и остальные отсутствующие ключи/партнёрские доступы перечислены в сравнении. Booking.com и прочие поставщики с неподтверждённым или исключённым российским покрытием не рекомендуются.

Для прототипа подключать напрямую только выбранные read-only инструменты официальных Tutu/2GIS MCP. Geoapify удобно через REST: меньше накладных расходов и проще проверка формата; MCP также успешно проверен. Community Aviasales MCP работает, но не добавляет данных относительно REST, использует GPL-3.0-or-later и отдельную среду; в MVP проще прямой Python-клиент.

Коммерческий запуск — отдельный этап: бесплатный ответ сервера не доказывает право перепродажи/хранения данных. Для Tutu нужно уточнить коммерческие условия и SLA; для карт — attribution/кэширование и тариф; для OpenTripMap/Open-Meteo — ограничения бесплатного плана. Документальные ссылки и ограничения каждого источника находятся в [каталоге](API_CATALOG.md), измерения — в [сравнении](API_COMPARISON.md).
