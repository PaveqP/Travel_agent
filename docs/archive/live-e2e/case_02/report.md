## Проблемы и невыполненные требования

- Требуемое сравнение самолёт/поезд не завершено: Tutu rail timeout; показана только авиа.
- Условия отмены отелей остались неизвестны; ключевой критерий пользователя не закрыт.
- Несмотря на десятки найденных POI и маршруты 2ГИС, программа пуста; Experience исчерпал tool/deadline и финализация TimeoutError.
- Начальный ответ 226.894s; часть задержки — необязательный для сравнения поиск программы и repair.
- Уточняющий вопрос о выборе первых двух вариантов вернул generic fallback «Не удалось подготовить ответ...» при HTTP 200. Выполнена одна диагностическая переформулировка, оба ответа сохранены.
- Диагностический повтор ответил, но назвал 22:50 временем вылета; в Candidate это arrival_at, а не departure_at. Неподтверждённый перенос смысла временного поля в presenter.

## Рекомендации

- При timeout транспорта сохранять частичный результат и адресно уточнять недостающую альтернативу без перезапуска остальных специалистов.
- Передавать условия отмены/питания из ответов поставщика в Candidate/результат и presenter вместо потери при нормализации.
- Для вопроса сравнения не блокировать ответ на полноте календаря активностей.
