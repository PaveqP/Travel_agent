# Проверка MCP и зависимостей

Community Aviasales: [stufently/aviasales-mcp](https://github.com/stufently/aviasales-mcp), commit `bba6ed42d37169fc027bf77d10f74675472bbe07`, GPL-3.0-or-later. Сохранены [SHA256 исходников](../reports/community_source_manifest.json) и [lock зависимостей](../requirements.community.lock.txt). Проведён просмотр Python-модулей, imports через AST, сетевых адресов, config/client/server/response обработки и реализации search_flights. Обнаружено 13 read-only инструментов Data API. В просмотренных исходниках не обнаружены вызовы shell/subprocess/exec; сетевой клиент ориентирован на api.travelpayouts.com. Это ограниченный code review, не сертификат безопасности зависимостей.

Исходники скачивались с GitHub по pinned commit, сторонние install.sh и npm postinstall не запускались. `setup_community_mcp.py` проверяет SHA256 до установки. Изолированная `.mcp-venv` использует совместимые версии FastMCP/Starlette, не меняя основную `.venv`. Установка Python wheel всё равно исполняет build backend; транзитивные зависимости и backend не прошли полный supply-chain аудит. Исходники и lock позволяют повторить проверку.

При stdio-запуске передаются только минимальный PATH и нужные переменные Aviasales. `.env` автоматически репозиторием не загружается; HTTP-режим сервера не используется. Логи выключены, stderr не сохраняется: upstream exception logging мог бы раскрыть данные запроса. Ключ применяется только к исходному Data API, не к LLM. GPL требует отдельной оценки модели распространения при включении исходников в продукт; для MVP рекомендован прямой REST.

Официальные удалённые MCP: Tutu, 2GIS, LiteAPI, Geoapify. Их серверный код не доступен этому аудиту; доверие ограничено документацией и измеренными ответами. Сохранены все tool descriptions/inputSchema. Даже инструменты с readOnlyHint не разрешаются автоматически: явный allowlist исключает checkout, пассажиров и финансовые операции. JSON Schema валидирует параметры до сети. Из LiteAPI доступны 95 инструментов, но вызывались лишь каталог и rates. OpenWeather MCP не установил соединение, его инструменты не считаются проверенными.

MCP-описания Tutu включают поведенческие указания и checkout_hint в результатах. Они не являются полномочиями пользователя и не должны попадать в доверенные инструкции оркестратора. Хранение JSON для аудита отделено от минимального набора полей, передаваемых модели.
