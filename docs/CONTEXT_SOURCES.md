# Ограничения, подъёмники и пляжи

Дополнение к 49 интеграциям: официальные информационные веб-источники, не подтверждённые API/MCP.

| Источник | Доступ / протокол | Подтверждено | Ограничение |
|---|---|---|---|
| [Роза Хутор: подъёмники](https://rosakhutor.ru/skiing/lifts/) | Публичная веб-страница, ключ не нужен | Владелец публикует текущие статусы подъёмников | Документированный публичный API не найден; автоматический сбор не реализован |
| [Роза Хутор: FAQ](https://rosakhutor.ru/faq/) | Публичная веб-страница | Ссылки на актуальные графики подъёмников, троп и активностей | Сезонное расписание не гарантирует открытие в конкретный день |
| [МЧС Краснодарского края](https://23.mchs.gov.ru/) | Официальный сайт | Кандидат для предупреждений | Унифицированный API ограничений туристических маршрутов не подтверждён; не тестировался как API |
| [Администрация Сочи](https://sochi.ru/) | Официальный сайт | Кандидат для муниципальных сообщений | Машиночитаемый актуальный реестр открытых пляжей не подтверждён |

В MVP показывать ссылку на официальный актуальный статус и время ручной проверки. Не извлекать скрытые endpoints сайта и не объявлять пляж/тропу безопасной по одному прогнозу погоды. Статус `unknown` должен оставаться unknown. Географические сведения/погода не заменяют распоряжение о закрытии. Для production нужны лицензированный feed или договорённость с оператором; коммерческое право автоматического сбора не установлено.
