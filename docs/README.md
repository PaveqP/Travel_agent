## Артефакты и проверки

`reports/` содержит исторические ответы API/MCP, схемы контрактов и нормализованные
примеры. Они нужны для воспроизводимости исследования и части offline-тестов;
не загружаются в пользовательскую БД и не входят в Docker-образы.
`tests/fixtures/` — тестовые данные с mock LLM/HTTP/MCP.
`scripts/` — ручные исследовательские и live-сценарии, не runtime backend.

Генерируемые трассировки ручных E2E-прогонов и снимок текущего прогресса исключены
из сдаваемого дерева. Итоги прежних прогонов сохранены в архиве, исходные JSON
доступны по ссылке на историю Git в его README. Новые локальные результаты
следует сохранять в игнорируемых `output/`, `tmp/` или `/tmp`.
Платные live-сценарии требуют отдельного разрешения и бюджета.
