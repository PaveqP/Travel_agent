# Изолированная проверка Tavily — 28.10.2026

Ключ в `.env` называется `TAVILY`. Загрузчик прежде принимал только `TAVILY_API_KEY`, поэтому система возвращала `missing_key`. Теперь `environment()` подставляет `TAVILY` как alias, если канонический ключ отсутствует или пуст. Непустой `TAVILY_API_KEY` имеет приоритет. `.env` не изменялся; секрет не выводился и не сохранён в отчёте.

Проверялись только реальные `tavily_search` и `tavily_extract`, зарегистрированные через `build_tools` для каждого специалиста. Не создавались LLM-клиенты, не запускались LangGraph, общий trip flow, MCP, бронирования или платежи. Финальный прогон сделал 6 HTTP-запросов к api.tavily.com: три Search и три Extract.

| Специалист | Тема | Search | Extract |
|---|---|---|---|
| Transport | Транспорт из аэропорта Сочи | 5 результатов | 3 страницы |
| Stay | Mirror Residence, услуги | 5 результатов | 3 страницы |
| Experience | Сочинский Дендрарий | 5 результатов | 3 страницы |

Extract вернул содержимое, а не только ссылки. В tools и сохранённые WebEvidence попали фрагменты по 2000 символов с каждой страницы — это лимит контекста системы, а не размер исходной страницы. Веб-цены остаются справочной информацией: `evidence=catalog`, без live quote и без цены в нормализованном предложении.

В первой попытке у Experience локальный DNS timeout одного сайта останавливал весь Extract ещё до запроса к Tavily и ошибочно назывался `forbidden`. Теперь такой URL пропускается с `timeout`/`network_error`, остальные проверенные адреса передаются в Extract; `skipped_urls` и warnings сохраняют причину. Неизвестные URL, приватные IP и подмена DNS на loopback блокируются до HTTP-запроса. DNS-проверка не отключалась.

Машиночитаемые результаты, включая первую попытку: [tavily_isolated_validation.json](../reports/tavily_isolated_validation.json). Отчёт содержит URL и размеры фрагментов, без ключа и полных текстов страниц.

Повторить отдельно, расходуя только Tavily-квоты:

```bash
.venv/bin/python scripts/smoke_tavily.py --read-only --output /tmp/tavily-smoke.json
```

Offline-тесты проверяют alias, приоритет конфигурации, Search/Extract и сохранение текста для всех ролей, отсутствие MCP-вызовов, каталог без подтверждённых цен, пропуск DNS timeout и запрет приватных/не найденных поиском URL. Общий пользовательский flow в live-режиме для этой задачи не запускался. Чтобы уже работающий backend увидел alias, процесс нужно перезапустить; Docker app — пересобрать.

Результат полного offline-набора: 126 тестов прошли, 5 отдельных PostgreSQL-тестов пропущены. Проверки diff, локальных Markdown-ссылок и Ruff F-check прошли.
