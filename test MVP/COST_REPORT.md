MODEL и BASE_URL не настроены. Определить модель, тариф, валюту биллинга и реальный provider usage невозможно. Исторические модели/цены из reports не применялись к новому запуску. ## Почему live остановлен до первого запроса

В `travel_agent/api.py` общий httpx-клиент не содержит budget hooks. UsageLogger пишет токены, но не общий денежный остаток. Лимиты ReAct не являются денежной гарантией. У `scripts/smoke_travel_agent.py` guard только LLM, оценка фиксирована $2/1M без доказанного тарифа текущей модели; MCP использует отдельный HTTP-клиент. Smoke вызывает внутренний граф и не заменяет пользовательский E2E. Запуск этого скрипта не выполнялся.

## Условие безопасного возобновления

После появления настоящей конфигурации сначала проверить официальные тарифы конкретного провайдера/модели и платных API; при неизвестной ограничиваемой цене не отправлять запрос. Один общий счётчик должен атомарно резервировать до отправки каждый LLM и API запрос, включая параллельные вызовы, retries и MCP transport, сохраняя pending reservations. Проверять spent + pending + консервативную верхнюю оценку нового вызова <= $4.50; $0.50 оставить на неизвестный/запаздывающий биллинг. Считать input с безопасной верхней границей по сериализованному запросу, output по max_tokens; cache discount заранее не учитывать. После ответа записывать usage/cached tokens/cost, освобождать резерв только при достоверной стоимости. При timeout оставлять весь резерв. Отсутствие счёта не считать нулём. Ни одной дополнительной попытки без доступного резерва, максимум одна диагностическая попытка кейса.
